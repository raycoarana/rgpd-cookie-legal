# WordPress.org directory assets

Place the plugin directory listing images in this folder. WordPress.org SVN uses these assets for the plugin page; they are submitted separately from the plugin zip.

Required filenames:

- `icon-128x128.png`
- `icon-256x256.png`
- `banner-772x250.png`
- `banner-1544x500.png`
- `screenshot-1.png` (and any additional screenshots as `screenshot-2.png`, `screenshot-3.png`, etc.)

Use PNG images at the dimensions indicated by each filename. No images are included yet.
